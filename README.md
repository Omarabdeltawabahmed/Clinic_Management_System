# Clinic Management System 

A comprehensive, web-based management solution designed to streamline daily healthcare operations, simplify appointment scheduling, and maintain electronic medical records. Built using **ASP.NET Core MVC** and **SQL Server**.

---

## Features

- **Doctor & Staff Portal**: Manage profiles, schedules, specializations, and working hours.
- **Patient Management**: Centralized records for medical history, prescriptions, and visit logs.
- **Appointment System**: Real-time booking, cancellation, and status tracking.
- **Role-Based Authorization**: Secure access control for Admin, Doctors, and Receptionists.

---

## Tech Stack

- **Backend**: C#, ASP.NET Core MVC, Entity Framework Core
- **Database**: Microsoft SQL Server
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **Authentication**: ASP.NET Core Identity
